Vigilex is an AI-powered observability and incident intelligence platform that helps engineering teams monitor applications, analyze logs, detect incidents, and perform AI-assisted root cause analysis through real-time dashboards and intelligent alerts. Built with Next.js and Tailwind CSS on the frontend, NestJS and PostgreSQL on the backend, with Docker and GitHub Actions for CI/CD.
